# Urban Land Potentiality Mapping
# Boumerdes – Algeria (2025)

# Project Overview
This project presents a GIS-based cartographic
study of urban land potentiality in Boumerdes.

### Objectives
- Identify potential urban land parcels.
- Map available land resources.
- Analyze spatial distribution.
- Support urban land management.

### Study Area
- Municipality: Boumerdes
- Wilaya: Boumerdes
- Country: Algeria

### GIS Tools
- ArcGIS Desktop 10.8
- Spatial Data Processing
- GIS Cartography

### Deliverables
- Thematic map (PDF)
- Cartographic representation
- Spatial analysis outputs
